Business scenario

A retailer wants to predict purchase probability.

An online retailer is promoting a new product. Its neural network receives three normalized signals about a visitor: Ad Engagement, Product Interest, and Price Sensitivity. The output is the probability that the visitor will purchase.

Important: This tiny network is intentionally simplified for learning. Real marketing systems may use many variables, stronger validation, privacy safeguards, fairness checks, and more appropriate model baselines.

What is an epoch?

One epoch means the network has processed every training example once. Ten epochs means it has cycled through the full dataset ten times.

The weights after an epoch are usually different from the weights before it because each example contributes a learning signal.

Training vs. inference

Training: prediction → compare with actual → calculate loss → backpropagate error → update parameters.

Inference: new input → trained model → prediction. The model normally uses its learned parameters without changing them for that prediction.

Concept map

What each part is doing

Input layerHolds the numerical features presented to the network.
WeightControls the current influence of one connection. Training changes weights.
BiasShifts a neuron's weighted sum before activation, giving the neuron flexibility beyond the inputs alone.
ActivationTransforms the weighted sum. This tutorial uses sigmoid so outputs are easy to interpret.
Loss functionMeasures how incompatible the model's prediction is with the known training outcome.
Learning rateControls the size of each parameter update. Too small can be slow; too large can be unstable.
Forward passMoves information from inputs through hidden neurons to the output.
BackpropagationComputes how model parameters contributed to loss so they can be adjusted.
InferenceUses the learned parameters to make a prediction for a new case.
Student challenge

Break the network on purpose.

Good experiments change one condition at a time and explain what changed.

1

Learning too slowly

Set η = 0.001. Train 20 epochs. Record how much the loss and prediction change.

2

Learning too aggressively

Reset. Set η = 1.0. Train repeatedly. Does loss fall smoothly, jump, or become unstable?

3

Move the decision threshold

Compare a 30%, 50%, and 80% threshold. The probability stays the same, but the business action can change.

4

Change the customer

Create a highly engaged but highly price-sensitive visitor. Explain why competing inputs can pull the output in different directions.

5

Training vs. inference

Switch to inference mode and change the customer inputs. Confirm that a prediction changes while the learned weights stay fixed.

6

Business interpretation

If coupons are sent whenever probability exceeds the threshold, explain one cost of setting the threshold too low and one cost of setting it too high.
