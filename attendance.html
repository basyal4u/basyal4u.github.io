Deployment note

This is a transparent classroom-kiosk prototype, not biometric identity verification or an official attendance database. A production system would need authenticated institutional accounts, instructor-controlled rosters, encrypted server storage, accessibility and alternative check-in procedures, consent/retention policy, and anti-spoofing review.
